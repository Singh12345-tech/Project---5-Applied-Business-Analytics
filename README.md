# Project-5: Applied Business Analytics

### Overview
This repository contains my notes on mathematical foundations required for Business Analytics, Data Science & Machine Learning.

Documented 50 key concepts from Linear Algebra, Calculus, Probability and Statistics that are essential for analytics and ML model building.

*Full Document:* Project-5.docx - contains complete 50 Q&A with formulas & examples.

- *Linear Algebra:* Vectors, Scalars, Matrices, Linear Transformation, Eigenvectors
- *Calculus for ML:* Gradient, Partial Derivatives, Backpropagation
- *Probability & Stats:* Probability Theory, Random Variables, CLT, Discrete vs Continuous (PMF/PDF), Joint & Marginal Distributions, Covariance, Percentiles & Quartiles, Sampling

Academic project to build strong fundamentals for business problem solving with data and understanding ML algorithms from scratch.
